# AI 工作管理工作台

面向个人开发者、产品设计人员和研发人员的本地工作管理工具，将 AI 对话、任务管理、迭代规划、领域设计与可视化笔记整合到同一工作空间，支持从需求讨论到执行跟踪的日常工作。

## 产品定位

以项目为中心组织工作，让 AI 辅助分析的结果能够进入实际管理流程。用户可以与 AI 讨论需求，将建议整理为工作项或领域模型，经确认后保存，再通过冲刺看板跟踪进度，通过画布补充思路与设计资料。

产品面向单用户本地使用，提供桌面客户端和本地 Web 界面，业务数据保存在本机。适合个人项目管理、AI 辅助需求分析、迭代交付跟踪及领域驱动设计（DDD）。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| **工作空间** | 按项目独立管理对话、工作项、冲刺、领域模型和笔记，支持创建、搜索与编辑。 |
| **AI 助手** | 支持连续对话、图片输入、历史恢复与工具执行过程查看；将工作项和模型草稿预览、编辑并确认保存。 |
| **可复用 AI 模板** | 在 AI 助手中创建或选择自定义模板，填写参数并关联工作项、领域模型，在新对话中执行；模板按工作空间保存并随备份迁移。 |
| **工作项管理** | 统一管理任务、缺陷与需求，设置优先级、截止时间和阻塞原因；支持搜索筛选、活动记录及回收站恢复。 |
| **冲刺看板** | 设置迭代目标和周期，拖动卡片推进状态；结束时结转未完成项，并保留历史冲刺快照。 |
| **领域模型** | 维护聚合根、实体、值对象、领域事件及处理器，记录字段与说明，通过“领域模型一张图”查看结构。 |
| **无边记** | 在自由画布中组合文字、图片、图形与连线，支持对齐排版、缩放及图片导出。 |
| **备份与恢复** | 备份单个工作空间，恢复为独立的新空间，便于保存和迁移项目资料；当前文件选择功能仅支持 macOS。 |
| **外部 AI 接入** | 通过 MCP 让外部 AI 客户端查询和更新工作项与冲刺，保留操作来源。 |

工作项覆盖待处理、进行中、待评审、待验证、待验收、已暂停、已完成及已取消等状态，可按实际工作流程推进。

## 典型使用流程

1. **建立工作空间**：为项目集中管理工作资料与上下文。
2. **讨论并整理需求**：与 AI 沟通，确认工作项或领域模型草稿。
3. **规划并推进工作**：将工作项加入冲刺，在看板中跟踪状态与阻塞。
4. **沉淀设计与成果**：维护领域模型、绘制可视化笔记，保留活动记录和迭代快照。

## 使用说明

本产品仅提供本地功能，仅限个人使用。

AI 助手需要本机 Codex CLI 及有效登录，模型与工具使用取决于账号权限和相关配置。当前产品尚未提供多用户在线协作或云同步。

日报管理正在开发中，计划用于记录每日工作、产出、进度、问题与明日计划。

安装、启动与配置请参阅 [开发与运行说明](src/README.md)。
