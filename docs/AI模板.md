# 可复用 AI 模板

入口在 AI 助手顶部的“AI 模板”。通过参数化模板启动普通 AI 对话，复用已有模型、历史记录、资料上下文和业务草稿确认能力。

## 使用

1. 点击“新建”创建自己的模板，或从已有模板列表选择。模板库不提供默认模板和搜索框。
2. 填写目标或业务描述，可补充额外要求。
3. 按需关联当前空间的工作项和领域模型，最多 12 项；资料选择每页 12 条。
4. 点击“在新对话中运行”。只有 Codex 已连接且当前回复结束后才能启动。
5. 在对话中查看结果并继续追问；保存业务数据沿用既有的草稿预览、编辑和确认流程。

当前正在编辑的对话输入会保留为该对话的草稿。若新对话发送失败，模板内容留在新对话输入框中，便于重新发送。

## 自定义

- 点击“新建”，填写名称、说明和模板指令。
- 在指令中使用 `{{目标}}`、`{{背景资料}}` 等占位符，使用时会生成对应的必填参数框。最多 12 个不同参数，名称不超过 40 个字符。
- 模板可以复制为新模板，再调整名称、参数和指令。
- 自定义模板可以编辑、复制和删除；删除模板不删除已有对话或业务数据。
- 当前输入框有内容时，可通过“从当前输入创建”保存为模板。

## 保存与边界

模板保存在当前工作空间的 SQLite 数据库中，支持备份恢复，写入使用版本校验以避免覆盖其他页面的修改。每个工作空间最多保存 60 个自定义模板，空工作空间默认没有任何模板。

模板可手动运行，创建一次 Codex 对话；各步骤由 Codex 在同一对话中执行。工作流页面保存每次执行的模板快照、参数、资料引用、状态与结果，支持查看产物、取消和使用相同参数重跑。引用资料通过真实 ID 和版本标识，要求助手读取最新内容。模板不会改变现有业务写入确认流程。

模板执行范围由用户保存的指令决定；涉及业务数据保存时继续遵循草稿预览和确认流程。

## 工作流执行记录

侧栏“工作流”展示执行记录，每页 12 条。运行记录链接到原 Codex 对话和已保存的业务产物；重跑沿用当时的模板与参数，并按真实 ID 读取最新资料。模型输出失败或客户端中断时保留记录，不自动重试已提交的请求。

备份包含模板与执行记录。恢复后的旧执行记录不会自动继续，可查看结果或手动重新运行。
