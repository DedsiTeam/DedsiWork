# UI 规范

采用克制、清晰的现代 SaaS 风格。页面背景为 `--background`，白色卡片使用 `--card`；文字、边框和交互状态沿用现有语义主题变量。

## 页面间距

- 工作空间内的业务页面统一使用 `--ui-page-padding-inline`（24px）和 `--ui-page-padding-block`（8px）作为外层内边距，与桌面容器已有留白叠加。
- 标题与内容之间统一使用 `--ui-page-heading-gap`（20px）；无边记工具栏与画布沿用同一间距。
- 对话、无边记和模型编辑等全高页面扣除顶部栏与桌面容器留白，保持底部完整可见。工作空间选择页无侧栏，四周统一留白 24px。
- 页面外层间距由 `src/web/surfaces.css` 统一管理，嵌套内容不重复添加页面内边距。
- AI 对话内容和输入框共用居中的阅读栏，最大宽度使用 `--ui-conversation-max-width`（880px），左右留白使用 `--ui-conversation-gutter` 并随窗口宽度调整，避免输入框横向铺满页面。
- 工作空间列表和业务页面共用横跨窗口的固定顶部栏，工作空间信息、返回列表和通知入口统一靠右，通知入口位于最右侧。侧栏从顶部栏下方开始；两类页面使用相同的内容起始间距和页标题排版。
- macOS 桌面顶部栏左侧使用 `--ui-native-controls-inset` 为原生窗口按钮留白；其余空白区域支持拖动和双击缩放，操作按钮独立响应点击。无边记画布同样保留顶部栏高度，避免遮挡内容。

## 圆角

圆角统一在 `src/web/index.css` 定义。业务样式引用语义变量，基础组件通过 `src/styles/globals.css` 的 Tailwind 映射使用同一套规则。

| 用途           | 变量                  | 当前尺寸        | 示例                                                       |
| -------------- | --------------------- | --------------- | ---------------------------------------------------------- |
| 微小几何细节   | `--ui-radius-detail`  | 2px             | 下划线端点、画布控制点                                     |
| 标签与徽标     | `--ui-radius-compact` | 6px             | 状态、类型、优先级、行内代码                               |
| 表单与菜单控件 | `--ui-radius-control` | 8px             | 输入框、选择器、菜单项                                     |
| 紧凑面板       | `--ui-radius-panel`   | 12px            | 冲刺卡片、工具面板、对话输入区                             |
| 主要卡片       | `--ui-radius-card`    | 20px            | 工作空间、工作项、领域模型、研发任务、日报、笔记、网址卡片 |
| 弹窗           | `--ui-radius-dialog`  | 20px            | 新建、编辑、确认弹窗                                       |
| 浮层           | `--ui-radius-popover` | 12px            | 下拉菜单、日期选择器、历史对话浮层                         |
| 按钮           | `--ui-radius-button`  | 999px（胶囊形） | 主按钮、次按钮、文字按钮、卡片进入按钮                     |
| 胶囊容器       | `--ui-radius-pill`    | 999px           | 悬浮侧栏与导航容器                                         |
| 圆形           | `--ui-radius-circle`  | 50%             | 圆形图标、选中背景、状态圆点                               |

- Tailwind 对应关系：`rounded-sm` 为 6px，`rounded-md` 为 8px，`rounded-lg` 为 12px，`rounded-xl` 为 20px。
- 新增样式使用上表变量，不在页面里新增独立圆角数值。需要新的尺寸时，先调整全局规范。
- 卡片内部优先用留白与文字层级分组，避免嵌套小卡片。贴合父容器边缘的子元素可用 `inherit`。
- 页面本身保持开放布局；表格、时间线、全高抽屉等原有直角结构继续使用 `0`。
- 所有操作按钮统一采用胶囊形，引用 `--ui-radius-button`，包括卡片里的进入按钮。等宽高的图标按钮自然呈圆形；输入框、选择器和菜单项仍为 8px 圆角。
- 交互状态保持同一圆角，悬停和选中通过主色的透明度、阴影或轻微位移表达，避免形状突变。

## 当前工作空间卡片

白底、20px 圆角、轻边框和轻阴影；名称突出，说明弱化，统计直接在卡片中排列，底部进入按钮与全局按钮保持一致，使用胶囊形。不显示最近打开时间。

## 业务卡片

公共卡片外观由 `src/web/cards.css` 管理，各模块样式负责内容排布。

- 工作空间、工作项、领域模型、研发任务、日报和无边记卡片统一白底、20px 圆角、24px 内容留白，网格间距通常为 20px。
- 标题统一为 16px / 600，辅助文字使用 `--muted-foreground`；空间名称沿用 18px。有图标的卡片使用 40px 圆形图标底座。
- 卡片内部通过留白分组，统计和元信息直接排列，不再套小卡片。底部操作不使用厚重分割线。
- 网址卡片采用更紧凑的 20px 留白和 14px 标题，最小宽度 200px，继续使用 20px 圆角。
- 普通内容卡片悬停和键盘焦点进入时使用轻阴影与 2px 上移；批量选中的工作项继续保留选中背景。减少动态效果模式关闭位移。
- 冲刺概览沿用主要卡片规范；可拖动的看板任务卡使用 12px 圆角、16px 留白和 14px 标题，只改变边框与阴影，不做悬停位移。

## 基础组件

组件外观统一由 `src/web/ui.css` 管理，基础尺寸与动效变量定义在 `src/web/index.css`。业务页面优先复用 `Button`、`Input`、`Textarea` 和 `Select`，不要另写同类控件的独立外观。

| 组件               | 规范                                                |
| ------------------ | --------------------------------------------------- |
| 普通按钮           | 高 36px，文字 13px，胶囊形                          |
| 单行输入、选择器   | 高 36px，文字 13px，圆角 8px                        |
| 小按钮与紧凑选择器 | 高 32px，文字 12px；按钮为胶囊形，选择器为 8px 圆角 |
| 大按钮             | 高 40px                                             |
| 图标按钮           | 默认 32px，小号 28px，大号 36px；不加水平内边距     |
| 图标               | 默认 16px，线宽 1.75                                |
| 多行输入           | 最小高度 88px，水平内边距 12px，上下 10px           |
| 菜单项             | 最小高度 32px，文字 12px，圆角 8px                  |
| 状态标签           | 文字 11px，圆角 6px，主色淡背景                       |

- 主按钮使用 `--primary` 与 `--primary-foreground`；次按钮使用白底轻边框；次要操作使用灰底或透明底。
- 按钮的尺寸使用 `size`，外观使用 `variant`；`data-size`、`data-variant` 供全局样式选择，不按业务名称定义另一套按钮。
- 表单使用白色背景和 `--input` 边框，占位文字使用 `--muted-foreground`；聚焦显示统一的 2px `--ring` 轮廓，偏移 2px。
- 禁用状态降低透明度并显示不可用光标；校验失败保留 `aria-invalid` 和错误提示，使用 `--destructive` 边框。
- 普通悬停与按下过渡为 180ms；菜单选中圆形继续保留既有的柔和滑动动画。遵循系统的减少动态效果设置。
- 弹窗、菜单使用白底、轻边框与全局浮层阴影，标题使用 18px / 600；全高抽屉继续与窗口边缘贴合。
- 工具栏和画布里的紧凑控件可保留专用尺寸，避免影响工作区密度。聊天输入、侧栏导航和圆形图标控件保留各自的语义形态；操作按钮统一采用胶囊形，菜单项、日历单元格及导航标签继续遵循各自的组件规范。

## 空状态

- 无数据、搜索无结果、回收站为空等场景统一复用 `src/web/components/empty-state.tsx` 的 `EmptyState`。
- 固定结构为图标、标题、二级说明，参考领域模型列表的空状态。标题说明当前状态，二级说明只保留一句简短指引，不在空状态里重复放新建按钮。
- 标准尺寸为 32px 图标、15px 标题、12px 二级说明，居中显示，无卡片外框和图标底座；颜色使用现有语义变量。
- 侧栏、弹窗、看板列、字段区等狭窄区域使用 `compact`，保持相同结构，缩小图标和留白。
- 加载状态和错误提示与空状态分别处理；数据摘要里的“暂无记录”等文字不强制扩展成完整面板。

## 分页

- 已有分页统一为每页 12 条，使用 `src/shared/pagination.ts` 的 `PAGE_SIZE`，前后端和总页数计算共用同一配置。
- 适用于工作项、领域模型、无边记、日报、活动记录，以及冲刺和关联资料等选择弹窗。
- 按搜索、筛选后的总数计算页数：`max(1, ceil(total / PAGE_SIZE))`；无数据时显示 `1 / 1`。
- 原来不分页的工作空间、研发任务主列表和网址导航保持原有展示方式。

## 修改后的交付

按当前协作约定，不运行测试；修改完成后沿用现有数据目录重新构建并重启桌面客户端，确认客户端和内嵌服务启动，由用户验证实际效果。

## 主色与派生色

- 主色为 `#080616`，统一定义在 `src/styles/globals.css` 的 `--theme-base`。正文、标题、主按钮及辅助状态沿用同一色相。
- 次要文字、边框、悬停与选中背景采用独立的全局配套浅色；页面继续使用语义主题变量，白色卡片与冷灰白页面形成层次。
- 调整主题时修改统一主色，不在业务页面单独设置主色色值。

- 主色 RGB 通道统一定义为 `--theme-base-rgb: 8 6 22`（`#080616`），`--theme-base` 从其生成。透明色使用 `rgb(var(--theme-base-rgb) / 透明度)`，避免构建压缩器错误折叠与 transparent 的 color-mix；更换主色时只修改 RGB 通道。

- 配套浅色统一定义在 globals.css：页面 `--theme-page: #F7F7F9`、辅助文字 `--theme-subtle: #777581`、悬停 `--theme-hover: #F0EFF3`、选中 `--theme-selected: #E8E6EE`、边框 `--theme-line: #E3E1E8`。这些语义配套色独立定义，不随主色机械套用透明度；白色卡片保持不变。
